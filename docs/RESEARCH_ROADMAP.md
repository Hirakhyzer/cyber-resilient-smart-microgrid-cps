# Research Roadmap

## v0.1 — reproducible reduced-order CPS baseline
Physical DERs, network effects, synthetic attacks/faults, digital twin, hybrid detector, trust, supervisor, EMS, metrics, tests, CI.

## v0.2 — temporal integrity and state estimation
EKF/UKF, timestamp/sequence consistency, rewritten-replay detection, change/stagnation statistics, detection delay.

## v0.3 — distributed intelligence
Agent-level local twins/trust, consensus under packet loss, source isolation, decentralized fallback.

## v0.4 — higher-fidelity grid model
Adapter for pandapower/OpenDSS/PyPSA or FMI; parameter mismatch and uncertainty studies.

## v0.5 — security-aware optimization
Constrained EMS/MPC with cyber risk, critical-load preservation, restoration objectives.

## v1.0 — reproducible publication artifact
Held-out benchmark suite, documented dataset interface, experiment manifests, stable API, archived release.
