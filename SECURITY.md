# Security Policy

This repository is a defensive, simulation-only research platform. It does not implement real utility, inverter, SCADA, or DER attack payloads.

Report software vulnerabilities privately through GitHub private vulnerability reporting if enabled, or contact the maintainer privately before publishing sensitive details. Include the affected commit, module, impact, and a minimal reproduction.

Do not use the synthetic attack modules against operational power systems. Real OT/DER testing requires explicit authorization, safety controls, and domain supervision.
